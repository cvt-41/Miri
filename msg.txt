Add first-start model picker that fits models to the PC

- On first start (and tray "Choose models…") Miri reads RAM and GPU
  memory and suggests a chat + vision model pair: Light, Balanced,
  Strong or Power. PCs without a 6 GB+ GPU are capped at Balanced so
  answers stay fast.
- Choosing a pair downloads it with progress, switches settings to it,
  then deletes the models it replaced. If a download fails or is
  cancelled, the old models stay.
- Reminds the user that Miri needs both: one model to answer and use
  apps, one vision model to see the screen.
- OllamaClient: PullAsync (streamed progress) and DeleteAsync.
- Installer mentions that model download can be skipped in favour of
  the picker. README and PLAN updated.
